# ECE445L Final Lab

A Bike Telemetry system that can track parameters such as heartrate, distance, speed, etc. It uses a ARM Cortex-M (TM4C123) microcontroller with reed switches, an LCD ST7735 display screen, and heart rate monitor. This was done using C and ARM Cortex-M Assembly as well as including a custom PCB and schematics done in KiCAD.
